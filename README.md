## 🎮 Project Overview
The **Hangman Game** is a fun and interactive word-guessing game built with **ReactJS**.  
Players try to guess a hidden word one letter at a time — every incorrect guess builds the hangman figure until the game ends!

This project demonstrates strong fundamentals in **React state management, conditional rendering, component reusability, and responsive design**.

---

## 🧰 Tech Stack
- ⚛️ **ReactJS** – for building interactive UI
- 💅 **CSS3 / SCSS** – for styling and layout
- 🧠 **JavaScript (ES6)** – for core game logic
- 🌐 **Netlify / Vercel** – for deployment

---

## 🔍 Features
✅ Random word selection for each game  
✅ Tracks guessed and remaining letters  
✅ Displays the hangman figure as mistakes increase  
✅ Responsive design for mobile & desktop  
✅ Option to reset and play again  
✅ Clear win/lose state alerts
